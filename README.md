# 🏙️ 서울·경기 부동산 통합 가격 비교 지도 (HousePrice)

🌐 **웹사이트 바로가기 (GitHub Pages):**  
👉 **[https://seunginp.github.io/HousePrice/](https://seunginp.github.io/HousePrice/)**

---

## 📌 주요 기능
1. **서울 25개 자치구 & 경기도 31개 시·군(주요 행정구 포함) 전체 비교**
   - 지도 줌 레벨에 따라 **시·군·구 평균 비교** ↔ **법정동 평균 비교** ↔ **개별 단지·매물 상세** 자동 전환 (수동 전환 버튼 지원)
2. **4대 부동산 데이터 출처 통합 비교**
   - **부동산공시가격 알리미** (공동주택 공시가격 및 현실화율)
   - **국토교통부 실거래가** (매매·전세·월세 신고 실거래가)
   - **네이버 부동산** (현재 매물 호가)
   - **KB 부동산** (KB 시세 일반가 · 상위평균가 · 하위평균가)
3. **거래 유형 · 부동산 유형 · 평수 · 층별 세밀한 필터링**
   - **거래 유형**: 매매 / 전세 / 월세(보증금·월세) / 공시가격
   - **부동산 유형**: 아파트 / 오피스텔 / 빌라·연립·다세대
   - **평수 구분**: `~19평(소형)`, `20평대`, `30평대`, `40평대`, `50평+(대형)` 및 평수 범위 직접 입력
   - **층별 구분**: `1층`, `저층(2~5층)`, `중층(6~15층)`, `고층(16층+)`, `탑층` 및 층수 범위 직접 입력
   - **단지 상세 분석**: 단지 내 **층별 가격 차이(1층 대비 로얄층 프리미엄 %)** 및 **평형별 전세가율·평당가** 차트/테이블 제공
4. **다중 지역·단지 비교함 & 실시간 API 수집 / 엑셀·CSV 업로드**
   - 여러 시/군/구나 단지를 비교함에 담아 한눈에 비교
   - 공공데이터포털 API 인증키 연동 및 엑셀(`.xlsx`)/CSV 파일 업로드 즉시 반영

## 🚀 로컬 백엔드 서버(FastAPI) 실행 방법
GitHub Pages 정적 웹앱 외에도 로컬에서 FastAPI + SQLite 백엔드 서버로 실행할 수 있습니다.

```bash
pip install fastapi uvicorn python-multipart pandas openpyxl requests
cd backend
python main.py
```
브라우저에서 `http://127.0.0.1:8000` 접속
